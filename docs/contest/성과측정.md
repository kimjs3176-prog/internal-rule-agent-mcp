# 정량 성과 측정 ① — 자동 처리 시간·정확도

## 측정 조건

| 항목 | 내용 |
|---|---|
| 측정일 | 2026-11-05 |
| 측정 데이터 | 한국농업기술진흥원 실제 내규 **126건(조문 3,456개)** |
| 실행 환경 | 리눅스 컨테이너(CPU 4개), Python 3.13, 로컬 서버(`run_local.py`), Chromium 브라우저(Playwright) |
| 측정 모드 | **AI 키 없이**(규칙 기반)·**외부망 없이**(법제처·알리오 접속 안 됨) — 업무망에서 AI를 못 쓰는 최소 조건 |

측정 스크립트는 다시 돌릴 수 있다.
- 서버 쪽: `python scripts/contest_bench.py`
- 화면 쪽: 서버를 띄운 뒤 `node scripts/contest_bench_ui.js`

처리 시간은 실행한 컴퓨터에 따라 달라진다. 아래 표의 시간은 같은 조건에서 3번 잰 범위다.

## 1. 대표 과제: 한 문장 요청부터 결과까지

화면 코드를 그대로 써서 끝까지 처리했다. 9건 모두 성공했다.

| 과제 | 처리 시간 | 결과 |
|---|---|---|
| 수치 바꾸기: “여비규정 제15조의 일비를 3만원으로 올려줘” | 0.51~0.53초 | 관련 별표 2의 표에서 일비 열만 25,000 → 30,000. 자료조사·인용 영향·점검·심의 사전검토·절차·검토 보고서·문서 세트까지 14단계. 개정문 왕복 검증 일치 |
| 낱말 바꾸기: “여비규정에서 여비를 출장비로 바꿔줘” | 0.89~1.43초 | 17개 조를 바꾸고 뒤 조사(을/를 등)도 맞춤. 개정문 왕복 검증 일치 |
| 조 삭제: “여비규정 제20조를 삭제해줘” | 0.43~0.53초 | 제20조 삭제. 이 조를 인용하는 제24조를 수정안 칸에 함께 담음. 개정문 왕복 검증 일치 |
| 조 신설: 제15조의2 신설 | 0.01초 | “제15조의2를 다음과 같이 신설한다.” 개정문 작성. 왕복 검증 일치 |
| 조 맞교환: 제16조 ↔ 제17조 | 0.02초 | 이동 개정문 작성. 인용 정정 대상 확인(해당 없음). 왕복 검증 일치 |
| 부칙 자동 작성 | 수치 바꾸기 과제 안에 포함 | “이 규정은 발령한 날부터 시행한다.” |
| 검토 보고서 초안 | 0.002초 | 6개 장: 추진 배경 및 목적 / 현황 및 문제점 / 자료조사 결과 / 개정 주요 내용 / 검토 의견 / 향후 추진 일정 |
| 문서 내려받기 | 0.03초 | 한글(HWPX) 19KB. 기본 선택 문서 6종을 한 파일로(심의안건서·개정문·신구조문대비표·개정 이유서·의견수렴 결과·사전검토 의견서) |
| 제정 초안: “업무용 드론 운영지침” | 0.80~0.84초 | 이름만 넣고 초안(4개 조) → 점검 오류 0 → 한글 16KB |

## 2. 개정문 왕복 검증: 전 내규

**방법**
- 내규 125건마다 아래 5가지 수정을 하나씩 해 본다.
- 만든 개정문을 현행 내규에 다시 적용해서, 그 결과가 수정안과 글자까지 같은지 확인한다.
- 조문이 없는 매뉴얼형 1건은 제외했다.

**결과: 619 / 619건 일치 (100%)**

| 수정 유형 | 일치 |
|---|---|
| 조 신설(제N조의2) | 121 / 121 |
| 항 끼워 넣기(뒤 항 번호가 밀림) | 124 / 124 |
| 조 삭제 | 125 / 125 |
| 조문 문장 추가 | 125 / 125 |
| 조 맞교환(인용 정정 포함) | 124 / 124 |

내규마다 시험 수가 다른 이유는 시험할 수 없는 경우를 뺐기 때문이다. 예를 들어 제N조의2가 이미 있거나, ①② 항이 있는 조가 없는 경우다.

> 개정문은 사람이 가장 많이 틀리는 문서다. 조·항 번호, “○○”를 “△△”로 한다는 문구, 신설·삭제 표현에서 틀리기 쉽다. 이 도구는 개정문을 만들 때마다 현행에 다시 적용해 보고 결과가 수정안과 다르면 바로 알린다.

## 3. 오류 주입 적발률: 조문 점검

**방법**
- 내규마다 사람이 흔히 내는 오류 10종을 하나씩 심는다.
- 조문 점검이 그 오류를 **새로** 짚는지 센다. 원래 있던 같은 종류의 문제는 빼고, 심은 조를 정확히 짚었는지도 함께 본다.

**결과: 1,243 / 1,243건 적발 (100%), 짚은 위치도 모두 정확**

| 심은 오류 | 적발 |
|---|---|
| 없는 조문 인용(“제999조에 따른다”) | 125 / 125 |
| 삭제된 조문 인용 | 125 / 125 |
| 조 번호 중복 | 125 / 125 |
| 조 번호 순서 뒤바뀜 | 125 / 125 |
| 조 제목 누락 | 125 / 125 |
| 부칙 누락 | 122 / 122 |
| 항 번호 건너뜀(① 다음 ③) | 121 / 121 |
| 옛 기관 명칭 사용(“농업기술실용화재단”) | 125 / 125 |
| 다른 내규의 없는 조문 인용 | 125 / 125 |
| 본문이 빈 조 | 125 / 125 |

측정 과정에서 바로잡은 것이 하나 있다.
- 처음 측정에서는 “다른 내규의 없는 조문 인용” 1건을 놓친 것으로 나왔다.
- 원인은 시험 설계였다. 인용 대상으로 조문 체계가 없는 매뉴얼형 문서(「여비업무 처리지침」)를 골랐는데, 이런 문서는 “제999조”가 있는지 없는지 판단할 근거가 없다.
- 그래서 조문 체계가 있는 내규만 인용 대상으로 쓰도록 바꿔 다시 쟀다.

## 해석과 한계

- **처리 시간**
  - 위 시간은 **도구가 처리하는 시간**이다. 사람이 결과를 읽고 확인하는 시간은 들어 있지 않다.
  - 수작업 기준 시간과의 비교는 「수작업비교.md」(정량 성과 ②)에 단계별 작업 분해로 정리했다.
- **AI 키 사용 시**
  - 자유로운 개정 의도로 수정안을 쓰는 경우 AI 응답 시간(수 초~수십 초)이 더해진다.
  - 이 문서의 수치는 AI 없이 규칙으로 처리하는 경우다.
- **외부 조회**
  - 법제처·알리오 조회(상위법 최신성, 다른 기관 사례)는 이 측정 환경에서 접속이 막혀 있어 빠졌다.
  - 망이 열린 환경에서는 조회 시간이 더해진다.
- **적발률 100%의 범위**
  - **심은 10가지 유형**에 대한 결과다. 모든 종류의 오류를 잡는다는 뜻은 아니다.
  - 내용상 판단(정책 타당성, 상위법 저촉 여부 등)은 심의 사전검토 단계에서 사람이 확인한다.
