## 회차 기록

### 11/4 오전 — 확산성①
- **회귀 점검:** 파이썬 테스트 348건, JS 테스트 72건 모두 통과. 핵심 흐름 4개(일비 3만원, 여비→출장비, 제20조 삭제, 드론 지침 제정)도 통과.
- **가상 기관 도입 시험:** 내규 7건을 0.06초에 들여옴. 기관 설정은 7개 항목만 바꿈. 코드 변경 없이 핵심 흐름이 돌았고, 화면 11개 어디에도 농진원 문구가 나오지 않음.
- **보강**
  - “15일의 연차휴가”처럼 숫자가 낱말 앞에 오는 수치 지시를 반영한다.
  - 수치 지시를 못 바꾸면 결론 줄에 이유를 보여 준다. 낱말이 없을 때는 비슷한 말로 다시 요청하는 버튼을 단다.
- **다음 회차에 넘김:** 내규관리규칙 조 번호(점검·심의·절차 근거)를 기관별로 고치는 항목, 구형 .hwp 안내.

### 11/4 오후 — 확산성②
- **회귀 점검:** 파이썬 테스트 349건, JS 테스트 74건 통과. 핵심 흐름 4개도 통과.
- **농진원 전용 하드코딩 전수 점검**
  - 화면·문서에 나가는 기관명·기관장·근거 규칙명은 이미 설정값을 쓰고 있었다.
  - 남은 하드코딩 2곳을 설정값으로 바꿨다.
    - 위원회 이름을 뽑을 때 “농진원”을 고정 낱말로 쓰던 곳
    - 결재선을 분류할 때 “원장”만 기관장으로 알아보던 곳(이제 “사장” 등 기관장 호칭도 인식)
  - 서버 시작 문구의 “KOAT”를 뺐다.
- **근거 조항 빈칸 처리**
  - 다른 기관이 근거 조 번호를 비워 두면 사전검토 의견서에 “필요성()”처럼 빈 괄호가 생기고, 절차표에는 「내규관리규칙」만 덩그러니 남았다.
  - 이제 근거가 비어 있으면 아예 적지 않는다.
- **도입 점검 도구 `scripts/check_org_config.py`**
  - 기관 설정의 실수를 사용 전에 찾는다: 근거 조항이 우리 규칙에 실제로 있는지, 기관명이 내규에 나오는지, 옛 명칭이 남았는지 등.
  - 운영 프로필은 근거 조항 37개가 모두 실제 조문에 있음을 확인했다. 옛 명칭 “실용화재단” 1곳도 찾았다.
  - 농진원 프로필을 가상 기관에 그대로 쓰면 36개를 틀렸다고 짚는다.
- **가상 기관 샘플 정리:** 근거 조항을 자기 규칙에 맞췄고, 절차 질문의 농업 분야 예시를 일반 표현으로 바꿨다.
- **도입 안내서:** 새 가상환경 기준 측정값 — 설치 9.5초, 들여오기 0.07초, 점검 0.26초, 서버 0.44초.
- **정정:** `.hwp`는 “원본 보관만”이 아니라 본문을 뽑아 변환한다. 스크립트 안내문과 오전 문서를 고쳤다.

### 11/4 추가(사용자 요청) — 상위법 개정 감시
- **찾는 것:** 지난 확인과 견줘 “새로 공포된 개정”(공포됐지만 시행 전 판이 새로 생김)과 “새로 시행된 개정”(현행 시행일이 바뀜).
- **함께 붙이는 것:** 그 규범을 인용하는 내규 목록.
- **화면**
  - 건강검진에 “상위법 변경 알림”을 두고 메뉴에 숫자를 띄운다.
  - 영향 조문 찾기 → 개정으로 이어지고, 확인함을 누르면 알림이 사라진다.
  - 화면을 열 때 하루 한 번 자동으로 확인한다(끄기 가능).
- **사내 서버:** `scripts/watch_laws.py`를 cron·작업 스케줄러로 매일 돌리면 사내 메신저 웹훅으로 알림을 보낸다.
- **검증:** 법제처 응답을 가짜로 바꿔 브라우저에서 확인했다 — 기준 저장 → 새 공포 알림·메뉴 숫자 → 영향 조문 찾기 → 확인함 → 다음날 자동 확인 → 끄면 조회 0건.
