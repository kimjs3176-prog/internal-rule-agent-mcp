## 화면 디자인

- **자막**
  - 화면 아래 가운데에 둔다. 두 줄 이내이고, 구절 단위로 직접 끊었다.
  - 바탕은 앱의 남색(#0f172a)이고, 불투명도 82%로 뒤 화면이 살짝 비친다. 모서리를 둥글게 하고 흐림 효과를 줬다.
  - 글자는 흰색 Pretendard 34px이다(11/6 사용자 요청으로 40px에서 줄임).
  - 수량(초·건·곳·번 등)만 브랜드 파랑의 밝은 톤(#93c5fd)으로 강조한다. 조 번호는 강조하지 않는다.
  - 어두운 카드 화면에서는 바탕을 흰색 반투명으로 바꾼다.
- **장면 표시:** 화면 위 가운데에 둔다. 브랜드 파랑(#2563eb) 반투명 알약 모양에 장면 번호를 넣었다.
- **포인터:** 누를 곳으로 포인터가 움직이고, 누르면 물결 표시가 나온다. 입력은 한 글자씩 친다.
- **검수:** 장면별 화면 12장을 한 장에 모아 보고 고쳤다. 고친 것은 다음과 같다.
  - 세 줄로 넘어가던 자막
  - 마지막 줄에 한 낱말만 남던 자막
  - 조 번호까지 강조되던 문제

## 다시 만드는 방법(실측 약 6분)

```
python run_local.py                                  # 서버(5100)
python scripts/contest_demo_tts.py F1 1.05           # 음성 서버(5200). 준비는 파일 머리말 참조
node scripts/contest_demo_video.js                   # 녹화 → demo_out/
python scripts/contest_demo_build.py demo_out demo_out/demo.mp4
```

- **음성 맞춤:** 녹화 시계와 영상 시작의 차이는 녹화마다 0~0.35초로 달랐다. 그래서 녹화 첫머리에 0.4초 동안 동기 표시(왼쪽 위 자홍색 네모)를 띄우고, 합칠 때 영상에서 그 표시를 찾아 차이를 스스로 잰다. 보정값(초)을 직접 넣을 수도 있다. 동기 표시는 완성본에서 표시 직전 화면으로 덮어 보이지 않는다.
- **녹화 결과**
  - 단계별 시간: `timing.json`
  - 자막 파일: `subs.srt`(접근성용, 별도 제출 가능)
  - 장면 캡처: `shots/`
- **녹화 스크립트가 함께 확인하는 것:** 페이지 오류 0건, 대화상자 0건(⑤ 장면 포함)

## 음성

- **엔진:** Supertonic 3(Supertone, 코드 MIT, 모델 OpenRAIL-M)으로 만들었다. CPU에서 오프라인으로 돌며, 10초 분량을 1.8초에 만든다.
- **목소리:** 여성 F1, 속도 1.2(11/6 사용자 요청으로 1.05에서 빠르게)
- **확인 방법:** 만든 음성을 음성 인식(faster-whisper small)으로 다시 받아 적어 자막과 대조했다.
  - 잘못 읽힌 곳은 읽는 글만 따로 고쳤다. 예: “0.6초”를 “영 점 육 초”로, “제24조”를 “제이십사조”로, “4건”을 “네 건”으로.
- **처음 고른 방법:** edge-tts(마이크로소프트 음성)를 쓰려 했으나 이 환경에서는 접속이 막혀 바꿨다.
- **사람 목소리로 바꾸려면:** `timing.json`의 자막 문장을 녹음해 같은 시각에 깔면 된다.
