# 모델 비종속 입증 — 제공자·모델 교체 시험

참가 안내서의 공통 개발 규칙은 “특정 모델에 종속되지 않을 것(2종 이상 모델 구동 입증 권장)”입니다. 이 문서는 두 부분으로 되어 있습니다.
1. 저장소에 넣은 자동 시험의 결과
2. 담당자가 실제 모델 2종으로 구동하고 촬영하는 절차

## 1. 자동 시험(`tests/test_model_swap.py`, 2026-11-07)

**방법:** 같은 제정 요청(“업무용 드론 운영지침”)과 개정 요청(「여비규정」 제17조 “근무지내 출장 여비를 현실화”)을 아래 다섯 경로로 보냅니다.
- 모델 서버는 시험 안에서 띄운 가짜 서버입니다. OpenAI 호환 형식과 Ollama 고유 형식을 둘 다 흉내 냅니다.
- 가짜 서버는 답에 자기를 부른 모델 이름을 적어 돌려줍니다. 그래서 실제로 어느 모델이 처리했는지 확인할 수 있습니다.

| # | 경로 | 바꾼 것 | 결과 |
|---|---|---|---|
| ① | 규칙 모드(AI 없음) | 없음 | 표준 조문 골격으로 제정 초안 작성 ✅ |
| ② | 사내·공통기반 모델 A(OpenAI 호환, vLLM 형식), `google/gemma-3-27b-it` | 서버 주소(환경변수), 화면에서 제공자 선택 | 제정 초안 2개 조, 키 없이 요청 ✅ |
| ③ | 같은 서버의 모델 B, `exaone-3.5-32b` | 화면에서 모델 이름만 | 개정 수정안(제17조 3만원·1만5천원)과 이유 작성 ✅ |
| ④ | 다른 OpenAI 호환 서버(행안부 AI 공통기반 가정), `gpt-oss-120b` | 관리자가 주소·키만 바꿈 | 개정 수정안 ✅. 새 서버에 키가 붙어 가고, 앞 서버로는 요청이 가지 않음 |
| ⑤ | Ollama 고유 API, `gemma2` | 제공자를 Ollama로 | 제정 초안 ✅(`/api/chat`) |

- **코드 변경 없음:** 다섯 경로 모두 코드를 고치지 않고 설정·화면 선택만 바꿨습니다.
- **같은 뒷단:** 결과는 같은 형식으로 같은 뒷단(대비표·개정문·검증·문서)에 넘어갑니다.
- **모델 목록:** 모델 서버가 알려 주는 목록(`GET /v1/models`)을 화면에 그대로 보여 줍니다.
- **Gemini·Claude·GPT:** 같은 공통 호출 함수(`_ai_generate`)로 부르며, 키만 있으면 화면에서 바로 교체됩니다. 실제 키가 필요해 자동 시험에는 넣지 않았습니다.

## 2. 실제 모델 2종 구동·촬영 절차(담당자용, 약 20분)

**예시 조합:** 외부 상용 모델 1종(Gemini) + 기관 PC에서 돌리는 공개 모델 1종(Gemma).

1. **사내 모델 준비(공개 모델)**
   - 기관 PC에 [Ollama](https://ollama.com)를 설치합니다.
   - `ollama pull gemma3:4b`로 모델을 받습니다(약 3GB, 일반 PC에서 동작).
   - 행안부 AI 공통기반 주소를 받았다면 1단계 대신 그 주소를 씁니다.
2. **서버 설정:** 아래처럼 실행합니다.
   - Windows는 `set OPENAI_COMPAT_BASE_URL=...` 뒤에 `python run_local.py`
   ```
   OPENAI_COMPAT_BASE_URL=http://localhost:11434/v1 python run_local.py
   ```
3. **사내 모델로 구동**
   - 화면 오른쪽 위 [AI 설정] → **사내·공통기반** 탭 → 모델 `gemma3:4b` → 저장(“AI 연결됨”)
   - 개정 화면에서 「여비규정」 제17조를 고르고, 개정 의도에 “근무지내 출장 여비를 현실화”를 적고 **수정안 만들기**를 누릅니다.
   - 확인·검토에서 **모두 점검하기**를 누릅니다.
4. **상용 모델로 교체**
   - [AI 설정] → **Gemini** 탭 → 키를 넣고 저장합니다.
   - 같은 개정 의도로 **수정안 만들기**를 누르고 점검합니다.
5. **촬영**
   - 3·4단계를 화면 녹화합니다. 두 번 모두 [AI 설정]에 보이는 제공자·모델명이 화면에 나오게 찍습니다.
   - 결과의 개정문 검증이 “일치”로 나오는 장면까지 담습니다.

**참고**
- 사내 모델(3단계)은 개정안이 기관 밖으로 나가지 않습니다. 공개 전 개정안은 이 경로를 권장합니다.
- 작은 모델은 수정안 문장이 거칠 수 있습니다. 그래도 개정문·대비표·검증은 규칙 엔진이 만들기 때문에 형식은 같습니다.
