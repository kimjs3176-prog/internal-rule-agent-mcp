# 정량 성과 ② — 수작업과 비교, 사람이 틀리기 쉬운 곳

이 문서는 「성과측정.md」(정량 성과 ①)의 측정값을 수작업과 비교한 것이다. 작업량은 실제 내규 데이터에서 셌다(`python scripts/contest_bench.py --workload`).

## 1. 수작업 시간 산정 방법

수작업 시간은 실제로 재지 않았다. 대신 **작업량(실측) × 건당 시간(가정)** 으로 계산했다.
- **작업량:** 실제 내규에서 사람이 찾고, 확인하고, 고쳐야 하는 곳의 수를 세었다.
- **건당 시간:** 아래 표의 가정값이다. 실무자 확인을 거치지 않았으므로, 담당자 경험치로 바꿔 넣으면 합계가 바로 다시 나온다.

| 기호 | 단계 | 건당 시간(가정) | 가정의 근거 |
|---|---|---|---|
| U1 | 조문·낱말 1곳 찾아 위치 기록 | 1분 | 한글 파일에서 찾기 → 앞뒤 문맥 읽기 → 메모 |
| U2 | 내규 1건을 열어 인용 여부 검색 | 1분 | 파일 열기 → 조 번호·내규명 검색 |
| U3 | 조문 1곳 고치기(문장·조사 맞춤) | 2분 | 고친 뒤 앞뒤 조사·띄어쓰기 확인 |
| U4 | 개정문 문장 1개 작성 | 5분 | 「○○ 중 “△△”를 “□□”로 한다」 같은 문형을 맞추고 조·항·호 위치 표기 |
| U5 | 신구조문대비표 1행 | 3분 | 현행·개정안을 옮기고 바뀐 곳 밑줄 표시 |
| U6 | 개정 이유서 / 검토 보고서 | 각 30분 | 서식에 배경·주요 내용 정리 |
| U7 | 제출 서식 1종(심의안건서·의견수렴 결과·사전검토 의견서) | 10분 | 서식 칸 채우기 |
| U8 | 최종 검수(조 번호·조사·표기) | 고친 곳 1곳당 1분 | 대비표·개정문·본문 대조 |

> 도구 처리 시간은 실측값이다(「성과측정.md」, AI 키·외부망 없이). 여기에는 **사람이 결과를 읽고 확인하는 시간이 들어 있지 않다.** 확인 시간은 11/6 시연 리허설에서 잰다.

## 2. 과제별 비교

### 과제 A — 「여비규정」 일비 25,000원 → 30,000원

| 단계 | 작업량(실측) | 수작업(가정 적용) | 도구 |
|---|---|---|---|
| 대상 찾기 | “일비”가 8곳 나옴(어느 값을 바꿀지 확인) | 8 × U1 = 8분 | 관련 별표 2의 “일비” 열만 골라 바꿈 |
| 인용·관련 확인(같은 내규) | 제15조를 인용하는 곳 3건 + 관련 별표 2개 | 5 × U2 = 5분 | 자동 |
| 인용 확인(다른 내규 전수) | 등록 내규 126건 | 126 × U2 = 126분 *(보통 생략 → 누락 위험)* | 자동(같은 처리 안에서) |
| 고치기 | 별표 2 표 2칸 | 2 × U3 = 4분 | 자동 |
| 개정문·대비표 | 문장 1개, 대비표 1행 | U4 + U5 = 8분 | 자동 + 왕복 검증 |
| 이유서·검토 보고서 | 2종 | 2 × U6 = 60분 | 자동 초안(보고서 6개 장) |
| 제출 서식 | 3종 | 3 × U7 = 30분 | 자동 초안 |
| 검수 | 고친 곳 2곳 | 2 × U8 = 2분 | 조문 점검 + 개정문 왕복 검증 |
| **합계** | | **117분** (다른 내규 전수 확인까지 하면 243분) | **0.5초** + 사람 확인 |

### 과제 B — 모든 내규에서 “기획운영본부” → “경영기획본부”(조직 개편)

| 단계 | 작업량(실측) | 수작업(가정 적용) | 도구 |
|---|---|---|---|
| 대상 찾기 | 내규 126건을 모두 검색해 **25개 내규 35곳**(별표·서식 6곳 포함) 확인 | 126 × U2 + 35 × U1 = 161분 | 자동 |
| 고치기 | 35곳(조사 맞춤 포함) | 35 × U3 = 70분 | 자동(조사 교정) |
| 내규별 개정문 | 25건 | 25 × U4 = 125분 | 자동 |
| 통합 신구조문대비표 | 35곳 | 35 × U5 = 105분 | 자동 |
| “다른 내규의 개정” 부칙 | 25건 | 25 × 2분 = 50분 | 자동 |
| 정비 이유서 | 1종 | U6 = 30분 | 자동 초안 |
| 검수 | 35곳 | 35 × U8 = 35분 | 자동 점검 |
| **합계** | | **576분(약 9.6시간, 하루 이상)** | **0.08~0.10초** + 사람 확인 |

### 과제 C — 「여비규정」 제20조 삭제

| 단계 | 작업량(실측) | 수작업(가정 적용) | 도구 |
|---|---|---|---|
| 대상 찾기 | 1곳 | U1 = 1분 | 자동 |
| 인용 확인(같은 내규) | 제20조를 인용하는 **제24조** 1건 | U2 = 1분 *(놓치기 가장 쉬운 곳)* | 자동으로 수정안 칸에 함께 담음 |
| 인용 확인(다른 내규 전수) | 126건 | 126 × U2 = 126분 *(보통 생략)* | 자동 |
| 고치기 | 삭제 1 + 인용 정정 1 | 2 × U3 = 4분 | 삭제 자동, 인용 정정 위치 짚어 줌 |
| 개정문·대비표 | 문장 2개, 대비표 2행 | 2 × (U4 + U5) = 16분 | 자동 + 왕복 검증 |
| 이유서·보고서·서식 | 2종 + 3종 | 60 + 30 = 90분 | 자동 초안 |
| 검수 | 2곳 | 2분 | 자동 점검(삭제된 조 인용을 오류로 짚음) |
| **합계** | | **114분** (다른 내규 전수 확인까지 하면 240분) | **0.4~0.5초** + 사람 확인 |

### 과제 D — 제정 「업무용 드론 운영지침」

도구는 **틀**을 0.8초 만에 만든다. 체계(목적·정의·…·부칙), 기관명, 시행일 부칙, 점검, 문서가 포함된다. 조문의 실제 내용은 사람이 채워야 하므로, 이 과제는 시간 비교 대신 “빈 문서에서 시작하지 않는다”는 점만 내세운다.
- AI 키가 있으면 내용 초안까지 쓴다.
- 망이 열려 있으면 다른 기관 사례를 함께 조사한다.

### 정리

| 과제 | 수작업(가정 적용) | 도구 처리(실측) |
|---|---|---|
| A. 수치 1곳 변경 | 약 2시간(다른 내규 전수 확인 시 약 4시간) | 0.5초 |
| B. 조직 명칭 일괄 변경(25개 내규) | 약 9.6시간 | 0.1초 |
| C. 조 삭제(인용 정정 포함) | 약 2시간(다른 내규 전수 확인 시 약 4시간) | 0.5초 |

**시간보다 큰 차이는 누락이다.** 수작업에서는 “다른 내규 126건을 다 열어 인용 확인”을 현실적으로 생략한다. 그래서 아래 3절처럼 현행 내규에도 고치지 못한 인용 오류가 남아 있다. 도구는 이 확인을 매번 전수로 한다.

## 3. 사람이 흔히 틀리는 유형 — 도구가 막는 방식과 실제 사례

“현행 내규의 실제 사례”는 지금 운영 중인 내규 126건을 조문 점검으로 훑어 나온 것이다. 표시는 둘로 나눴다.
- **✔ 확인함:** 원문과 직접 대조해 오류임을 확인한 건
- **표시:** 도구가 짚었지만 아직 사람이 확인하지 않은 건(일부는 서식 안의 조문 등 오탐일 수 있다)

| 유형 | 도구가 막는 방식 | 현행 내규의 실제 사례 |
|---|---|---|
| **인용 조 번호 오류·누락**<br>조를 지우거나 옮긴 뒤 인용한 곳을 못 고침 | 조를 삭제·이동하면 그 조를 인용하는 같은 내규·다른 내규 조문을 찾는다. 같은 내규의 인용 조는 수정안 칸에 함께 담는다(예: 제20조 삭제 → 제24조). 없는 조·삭제된 조 인용은 오류로 짚는다 | ✔ 「종자산업진흥센터 시험분석 의뢰 및 처리규칙」 제8조가 제17조를 인용하지만 이 규칙은 제16조까지다<br>✔ 「유연근무제 운영규칙」 제33조가 삭제된 「직원채용지침」 제59조를 인용한다<br>✔ 「윤리경영규정」 제31조가 「임직원 행동강령」에 없는 제6조의5를 인용한다 |
| **항 번호 오류** | 항 번호가 ①②③ 차례가 아니면 오류로 짚는다. 항을 끼워 넣으면 뒤 항 번호를 밀고 개정문을 맞춘다(왕복 검증 124/124) | ✔ 「내부성과평가규칙」 제35조: ② 다음에 또 ②<br>✔ 「사택관리규칙」 제7조: ① 없이 ②부터 시작<br>✔ 「종자산업진흥센터 시험분석 등의 수수료 규정」 제3조: ① 다음 ② 표시 없이 ③<br>표시: 7개 내규 7건 |
| **호·목 번호 오류** | 호(1. 2.)·목(가. 나.) 순서를 점검한다 | 표시: 호 10건(9개 내규), 목 2건. 예: 「재무회계규정」 제106조 호 번호 1, 2, 4, 5, 6 |
| **조사 불일치**<br>명칭을 바꾼 뒤 “을/를·은/는”을 못 고침 | 낱말을 바꿀 때 받침에 맞춰 조사를 함께 고친다. 다른 말의 일부(합성어)는 건드리지 않는다 | 일괄 정비 실측: 「직제규정」 “윤리감사실**을** 둔다” → “감사부**를** 둔다”, “윤리감사실**은**” → “감사부**는**” |
| **옛 명칭 잔존** | 기관 설정의 옛 명칭(이사장·재단 등)이 남은 곳을 짚는다 | 표시: 5개 내규 5곳. 예: 「공모직위 지정 및 운영에 관한 지침」 제15조 “재단”, 「명예퇴직수당 지급규칙」 별표의 “이사장” |
| **바뀐 내규명 미반영** | 본문이 인용하는 내규명이 현행 목록에 없으면 비슷한 현행 이름과 함께 짚는다 | 표시: 6개 내규 7건. 예: 「내규관리규칙」 제2조가 「위임전결규정」을 인용하지만 현행 이름은 「위임전결규칙」 |
| **별표·서식 인용 누락** | 본문이 인용한 별표·서식이 실제로 있는지 본다 | 표시: 5개 내규 9건. 예: 「분석시험 등의 수수료 규정」이 [별표 4]를 인용하지만 별표가 없다(별도 파일 여부 확인 필요) |
| **부칙 누락** | 시행일 부칙을 자동으로 만든다(“이 규정은 발령한 날부터 시행한다.”). 부칙이 없으면 짚는다 | 표시: 3건(「데이터 관리 규칙」, 운영 매뉴얼 2건) |
| **용어 정의 중복** | 같은 용어를 두 조에서 정의하면 짚는다 | 표시: 5개 내규 7건. 예: 「감사규정」 “감사인”을 제2조·제8조에서 각각 정의 |
| **대비표·개정문 오기** | 개정문과 대비표를 같은 수정안에서 만든다. 개정문을 현행에 다시 적용해 수정안과 다르면 바로 알린다 | 전 내규 왕복 검증 619/619 일치(「성과측정.md」) |
| **애매한 수치를 짐작으로 고침** | 같은 낱말의 값이 여러 곳에 서로 다르게 있으면 바꾸지 않고 위치를 알린다 | 「복무규정」 “연차 일수를 20일로” → “제27조 1일·15일 / 제31조 1일 — 어느 값인지 추측하지 않았습니다” |

## 4. 한계와 확인할 일

- **건당 시간은 가정이다.** 결선 질의에서 근거를 물을 수 있다. 출품 전에 담당자 1~2명의 실제 경험치(예: 「여비규정」 한 건 개정에 실제로 걸린 시간)로 바꿔 넣기를 권한다. 1절 표의 값만 바꾸면 2절 합계가 바로 다시 계산된다.
- **“표시” 건은 사람 확인이 필요하다.** 일부는 오탐일 수 있다. 예: 「농업공공기술진흥사업 운영 매뉴얼」의 제12조 중복은 뒤에 붙은 협약서 양식의 조문 때문이다.
- **도구 시간에는 사람 확인이 빠져 있다.** 결과를 읽고 확인하는 시간은 11/6 시연 리허설에서 함께 잰다.
