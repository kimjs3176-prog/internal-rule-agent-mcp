# 구동안내서 실제 구동 검증 (2026-11-06)

- **목적:** 심사위원이 구동안내서(「구동안내서.md」, 양식 2-1)만 보고 따라 했을 때 실제로 동작하는지 확인한다.
- **방법:** 깨끗한 새 폴더에서 처음부터 안내서의 명령을 그대로 실행했다.
  - 화면 기능은 사람이 하듯 화면의 단추 글자를 찾아 눌렀다(`scripts/contest_guide_check.js`, 16개 항목).
  - AI 키와 외부망(법제처·알리오) 없이 진행했다.
- **환경:** 리눅스, Python 3.12.3(안내서의 최저 버전), Chromium
- **결과:** 모든 단계가 안내서대로 동작했다. 안내서와 화면 글자가 다른 곳 5곳은 안내서를 고쳤다.

## 6. 검증에서 고친 것

- **구동안내서 문구:** 화면 글자와 다르거나 실측과 다른 곳을 고쳤다.
  - AI 단추 이름: 키를 넣기 전에는 “AI 미설정”으로 보인다.
  - 위임 조항 단추 이름: “직접 입력”이다.
  - 점검 단추 이름: “모두 점검하기”다.
  - 첫 진단 시간: 서버를 켠 직후에는 약 3초다.
  - 메모리: 모든 기능을 쓴 뒤 약 114MB다.
- **`.gitignore`:** 안내서대로 만든 `.venv/`가 git에 새 파일로 잡혀 추가했다.
