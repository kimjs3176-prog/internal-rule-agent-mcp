## 화면별 기능

| 화면 | 하는 일 |
|---|---|
| ✦ 에이전트 | 한 문장 지시(“여비규정 제15조 일비를 3만원으로”, “개인정보 유출을 막기 위해 개인정보 처리지침을 새로 만들어줘”) → 대상 찾기·**자료 조사**(우리 기관 관련 내규·조문, 그 내규들이 인용한 법령, 다른 기관 사례, 인용 영향)·초안·영향 분석·점검·**검토 보고서 초안**(추진 배경·목적 → 현황 및 문제점 → 자료조사 결과 → 주요 내용·신구 대비 → 검토 의견 → 향후 추진 일정 → 붙임)·문서까지 한 번에. 목적 구절(“…을 위해”)은 떼어 추진 배경·목적으로, 조를 적은 요청은 그 조만 빠르게 |
| 🩺 건강검진 | **진단 요약**(전체 내규 점수·등급, 정비 우선순위, 상위법·행정규칙(훈령·고시 등) 개정 미반영 — 법제처에서 못 찾은 이름은 따로 표시, 곧 시행되는 상위법, 중복 등록 의심, 별표·서식의 옛 기관명·직위) · **오류 목록**(인용·명칭·조 번호 오류를 내규별로, 같은 문장인데 수치만 다른 곳) · **내규 하나 점검**(항·호 순서·표기·부칙·별표 인용까지). 조문을 읽지 못한 내규는 점수 대신 “읽지 못함”으로 표시 |
| 💬 내규 자문 | 직원 질의에 근거 조문을 찾아 회신서 작성(AI 인용은 원문과 대조해 표시), 같은 쟁점의 법제처 법령해석례 참고 |
| 📖 용어 사전 | 내규의 정의 조항·약칭 모음(규정 온톨로지 1단계). 같은 용어를 내규마다 다르게 정의하면 ‘정의 불일치’로 표시하고 조문 점검·자문이 알림, 일상어↔내규 용어 동의어 추가, SKOS(JSON-LD) 내보내기 |
| 🏢 조직·권한 | 직제 조문으로 만든 조직도(본부·실·팀·센터와 분장 업무), 위원회 설치 조문에서 뽑은 구성 인원·위원장·간사·심의 사항(규정 온톨로지 2단계), 직위·기능 부서가 나온 조문, 직제에 없는 옛 조직명 찾기 → 일괄 정비. **권한·절차**(3단계): 조문 문장의 누가·무엇을(승인·보고·심의 …)·누구에게·언제(기한)·의무/재량/금지와 위임전결 별표의 전결권자 — 내규 자문이 “누가 결재하나요?”에 전결권자를 함께 답함 |
| 🆕 제정 · ✏️ 개정 | **단계에 들어서면 그 단계 일을 먼저 해 둠**(사용자는 확인하고 고친다): 제정은 내규명을 적으면 다른 기관(알리오) 같은 종류 규정을 찾아 관련 조문을 미리 담고, “초안까지 한 번에”로 여러 기관이 공통으로 둔 조(예: 운영책임자·비행 승인·사고 보고)를 넣은 초안과 **조문별 참고 출처**를 만들며(AI 키가 없어도), 점검 단계는 자동 실행. 개정은 고른 조문을 고치기 칸에 자동으로 담고(AI 키와 개정 의도가 있으면 AI 수정안), **고치기 화면에서 개정 의도를 다 적고 칸 밖을 누르면(또는 Ctrl+Enter) 바로 수정안을 만듦**(AI 키가 없어도 “일비를 3만원으로”(수치)·“여비를 출장비로 바꿔”(낱말 — **조 번호를 적으면(“제15조의 여비를 출장비로”) 그 조만** 바로 바꾸고 다른 조의 같은 말은 위치만 알림, 조 번호가 없으면 **내규 안 모든 곳**에서, 의·에서 등 조사형까지 바꾸고 뒤 조사를 맞춤. 합성어 안쪽(국내여비)은 그대로 두고 그 위치를 알려 줌. 그 내규에 없는 말이면 바꾸지 않고 “모든 내규 일괄 정비”로 이어 줌)·“제7조 삭제”는 바로 반영하고(**사람이 틀리기 쉬운 곳을 추측하지 않음**: “연차휴가 일수를 20일로”처럼 바꿀 값이 여러 곳에 서로 다르게 있으면 자동으로 바꾸지 않고 후보를 보여 주며, 찾는 말이 없으면 내규에 있는 비슷한 말을 알려 줌), 고른 조문이 없으면 그 말이 든 조문·별표를 내규에서 찾아 담음. 사람이 이미 고친 수정안은 자동으로 덮어쓰지 않음), 확인·검토에 들어서면 모두 점검. **제정 초안도 색 표시**: 만든 초안에서 고친 곳(파란 바탕)과 아직 채울 자리표시 ○○·△△(노란 바탕, “다음 채울 곳” 버튼으로 하나씩 골라 바로 입력)를 보여 주고, 표준 골격의 적용범위 조는 제정 목적으로 채움. **바뀐 문구는 색으로 표시**: 현행 칸은 지운 말을 빨간 밑줄로, 개정안 입력칸은 새로 넣은 말 뒤에 파란 바탕을 깔아(입력칸은 그대로 고칠 수 있음) 고치는 동안 바로 따라감. **지시문의 수치는 AI 없이도 반영**(“일비를 3만원으로” → 별표 2 표의 “일 비” 열만 25,000 → 30,000, 식비 열은 그대로 — 표의 머리 줄과 행의 칸 수가 맞을 때만 바꾸고 아니면 손대지 않음). 고치기 화면은 수정안이 생기면 시행일·참고 자료·도구를 “세부 설정·도구”로, 개정 이유·부칙을 접어 두고(비우면 자동 작성), 그대로인 조문 카드는 한 줄로 접음. 조문 초안·수정안, **조 번호 도구**(조 이동·맞교환·빈 번호 메우기 — 같은 규정 안의 인용은 자동 정정, 개정문은 “제9조를 제8조로 한다.”), 확인·검토 한 줄 요약(“모두 점검하기” 한 번으로 대비표·영향·점검·같은 문장·개정문 검증·사전검토), **개정문 검증**(만든 개정문을 현행에 되돌려 적용해 수정안과 같은지 확인), 별표·서식 수정(금액표·결재 서식도 조문처럼 골라 고치고 개정문·대비표에 반영, 고친 조문의 관련 별표는 자동으로 담음), 유관 기관 수치 비교(알리오), 신구조문대비표, 인용 영향 분석, 같은 문장이 있는 다른 곳(함께 고칠 곳), 심의 사전검토, 심의 제출 패키지(.hwpx·.docx) |
| 🧩 일괄 정비 | 바뀐 기관명·직위·내규명을 모든 내규에서 조사까지 맞춰 바꾸고 개정문·부칙 작성 |
| 🏛 상위법 영향 | 법령 개정에 영향받는 내규 조문 찾기(약칭 “법 제N조”·“같은 법”까지). **법령 조문 지도**(규정 온톨로지 4단계): 내규가 인용한 법령의 조 단위 연결 — 법령 → 조 → 그 조를 인용한 내규 조문, 법제처 현행 조문과 대조(없어진·삭제된 조 표시), 조를 눌러 바로 영향 분석 |
| 📚 내규 목록 | 내규 찾기·조문 보기, 조문 연혁(업로드된 판마다 바뀐 내용 비교) |
| 🕸 인용 관계 | 내규 사이 인용 관계·파급 범위 |
| 🗂 절차 안내 | 기관 절차에 맞춘 단계·일정·추진계획표 |
| 🧾 작업 실적 | 저장한 산출물의 AI 활용·사람 검토 기록(기관 전체 월별 실적은 켤 때만) |

다른 공공기관 사규(알리오)를 찾아 초안 참고로 쓸 수 있습니다.

## 화면 구성

**처음 쓰는 사람**: 첫 화면에 “처음 오셨나요?” 시작 안내(① 한 문장으로 맡기기 ② 우리 내규 상태 보기 ③ 단계별로 직접 하기)가 나오고, 오른쪽 위 **도움말** 하나에서 언제든 30초 둘러보기(화면의 주요 부분을 차례로 짚음)·메뉴 안내·용어 풀이(개정문·신구조문대비표·부칙·별표 등)와 **설정·보관**(AI 설정·AI 키 발급·작업 백업·복원·근거 규정)을 찾을 수 있습니다. 화면 머리에는 제목·도움말·AI 상태만 둡니다. 주요 메뉴 넷에는 한 줄 설명(한 문장으로 맡기기·우리 내규 상태 보기·있는 내규 고치기·새 내규 만들기)이 붙어 있습니다.

왼쪽 메뉴는 **작업**(에이전트·건강검진·개정·제정) 넷과 접힌 **더 보기** 하나뿐입니다. 더 보기를 누르면 찾아보기(내규 목록·자문·용어 사전·조직·권한)·정비 도구(일괄 정비·상위법 영향·인용 관계)·관리(절차 안내·작업 실적)가 소제목과 함께 펼쳐집니다. 에이전트 첫 화면의 예시는 종류별 하나씩 넷만 보이고 나머지는 “예시 더 보기”에 있습니다. 옛 “전체 점검”은 건강검진의 “오류 목록·내규 하나 점검” 보기로 들어갔습니다.

## 지자체·중앙부처에서 쓰기(자치법규·행정규칙)

규정을 읽고(조·항·호·목, 부칙, 별표·서식), 개정문과 신구조문대비표를 만들고, 인용·명칭·번호를 점검하고, 상위법을 법제처에서 대조하는 엔진은 **문서 종류를 가리지 않습니다**. 조례·규칙·훈령·예규·고시도 같은 틀로 다룹니다.

- **바로 해 보기(설치 없이)**: 개정 화면의 **원문 붙여넣기**에 조례 전문을 붙여 넣으면 개정안·개정문(“○○ 조례 일부개정조례안”)·대비표·점검·개정문 검증이 그대로 동작합니다. 부칙 기본 문구도 “이 조례는 공포한 날부터 시행한다.”로 바뀝니다.
- **기관 전체로 쓰기**: 가상의 ‘가온군’ 예시 프로필과 자치법규 2건을 `samples/local_gov/`에 두었습니다.
  ```bash
  export ORG_CONFIG=samples/local_gov/org_config.json REG_DIR=lg/regulations REG_MANIFEST=lg/manifest.json   # 결과는 별도 폴더(lg)에
  python scripts/import_regulations.py samples/local_gov/regs --reset   # 조례·시행규칙 등록
  python run_local.py                                                   # 군수·자치법규·입법예고 기준으로 동작
  ```
  건강검진은 조례가 인용한 「농업기계화 촉진법」·「지방자치법」을, 인용 영향은 조례 ↔ 시행규칙 관계와 별표 1을 찾습니다(테스트 `tests/test_local_gov.py`).
- **다른 점만 바꾸면 됩니다**: 기관장·규정 낱말(`reg_word`: 내규 → 자치법규), 심의기준(`review_criteria`: 상위 법령 정합성·입법예고), 절차(`procedure`). 알리오 비교는 공공기관 전용이므로 지자체에서는 비워 둡니다.

## 개발 중 검증 기록(2026. 10., 등록 내규 126건 기준)

- **건강검진**: 보고된 문제 16건(없는 조 인용, 다른 내규의 삭제된 조 인용, 바뀐 내규명 7건, 옛 명칭, 조 번호 중복, 중복 등록)을 원문과 대조해 **16건 모두 실제 결함**. 일부러 심은 오류 10종 중 8종 탐지(나머지 2종은 이후 보강: 별표·서식의 옛 명칭, 조문을 읽지 못한 내규 표시).
- **지시문 해석**(규칙 기반, AI 없음): 30건 중 모드 30/30, 대상 내규 19/19, 대상 조문 14/15.
- **개정문 왕복 검증**: 내규 126건에 무작위 개정(글자 바꾸기·단서·항 신설·끼워 넣기·삭제·조 신설 등)을 가해 개정문을 만들고 그 개정문을 현행에 되돌려 적용하면 수정안과 일치 — 6개 시드 **1,279건 중 1,279건(100%)**. `python scripts/roundtrip_amend.py`로 재현하며, 테스트(`tests/test_verify_fixes.py`)에 포함. 화면의 “확인·검토 → 개정문 검증”이 같은 함수로 매 개정안을 검증합니다.
- **끝까지 실행**: “여비규정 제15조의 일비를 3만원으로” 한 문장 → 제15조·관련 별표 2·4 자동 연결 → 별표 2 “일 비” 열 숫자 자동 수정 → 영향분석·점검·사전검토·개정문 검증 → 개정문·대비표·한글 저장까지 사람이 하는 일은 결과 확인과 제안 부서 입력뿐.
