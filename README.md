## 무엇을 하나요

규정을 고칠 때 AI 혼자서는 틀리기 쉬운 일을 이 도구가 맡습니다. AI가 고친 조문을 넘기면, 개정문과 검증·문서는 서버의 규칙 엔진이 만듭니다. 그래서 어떤 AI에 연결해도 결과가 같습니다.

| | 하는 일 |
|:---:|---|
| ✍️ | **개정문** — “제15조제1항 중 ‘2만원’을 ‘3만원’으로 한다.” 같은 문형을 규칙대로 만듭니다 |
| ✅ | **개정문 검증** — 만든 개정문을 현행에 적용해 수정안과 같은지 기계적으로 확인합니다 |
| 🔍 | **조문 점검** — 없는 조문 인용, 항·호 번호, 옛 명칭, 시행일, 그 조를 인용하는 다른 조를 찾습니다 |
| 📄 | **문서** — 심의안건서·개정문·신구조문대비표·이유서를 한글(hwpx)·Word(docx)로 줍니다 |
| 🏢 | **어느 기관이든** — 알리오 공시 규정이나 붙여 넣은 원문만 있으면 그 기관 이름으로 만듭니다 |

## 🔗 1분 등록

### 커넥터 주소

```
https://reg-agent-mcp.vercel.app/mcp
```

인증은 필요 없습니다. 주소를 브라우저로 열면 같은 연결 안내가 나옵니다.
기관 전용 주소를 받았다면 그 주소 끝에 `/mcp`를 붙여 씁니다. 기관 주소에서는 등록된 내규 전체를 다루는 기능(한 문장 처리·건강검진·일괄 정비)도 씁니다.

### claude.ai — 웹·데스크톱·모바일

| 단계 | 할 일 |
|:---:|---|
| 1 | **설정 → 커넥터**에서 **사용자 지정 커넥터 추가** |
| 2 | 이름(예: `규정 제·개정 에이전트`)과 위 주소 입력, 고급 설정(인증)은 비움 |
| 3 | **추가** |
| 4 | 새 대화의 입력창 **도구 메뉴**에서 이 커넥터를 켬 |

팀·기업 요금제에서는 조직 관리자가 먼저 추가해야 구성원이 켤 수 있습니다.

### ChatGPT

| 단계 | 할 일 |
|:---:|---|
| 1 | **설정 → 앱·커넥터 → 고급 설정**에서 **개발자 모드**를 켬 |
| 2 | 앱·커넥터 화면에서 **만들기** |
| 3 | 이름과 위 주소 입력, 인증은 **없음** |
| 4 | 새 대화의 **＋ 메뉴 → 개발자 모드**에서 이 커넥터를 고름 |

## 💬 첫 요청

커넥터를 켠 대화창에 그대로 적어 봅니다.

| 이렇게 요청하면 | 이렇게 받습니다 |
|---|---|
| `한국○○공사 여비규정을 알리오에서 찾아 일비를 3만원으로 올리는 개정안 만들어줘` | 그 기관 이름으로 된 개정문 · 대비표 · 검증 결과 · 문서 링크 |
| (원문을 붙여 넣고) `이 규정 형식 점검해줘. 우리 기관은 ○○재단, 기관장은 이사장이야` | 없는 조 인용 · 번호 · 시행일 등 점검 결과 |
| `유관 기관 여비규정의 일비를 비교해줘` | 기관별 값과 최솟값 · 중앙값 · 최댓값 |
| `연구윤리 규정을 새로 만들려고 해. 초안 쓰고 점검해서 제정 문서까지 만들어 줘` | 조문 점검 · 심의 사전검토 · 제정 문서 세트 |

**잘 쓰는 요령**
- **기관명·기관장 직위·규정을 부르는 말**(사규·내규·자치법규)을 알려 주면 개정문과 문서에 그대로 들어갑니다.
- 다른 기관 사례를 참고했다면 “참고한 조문을 근거로 남겨 줘”라고 하세요. 검토 보고서에 근거로 남습니다.
- 기관 전용 주소라면 `모든 내규에서 기획운영본부를 경영기획본부로 바꿔 줘` 같은 한 문장 요청도 됩니다.

## 📦 받는 것

| 항목 | 내용 |
|---|---|
| 개정문 | “○○ 일부를 다음과 같이 개정한다.” + 부칙 |
| 신구조문대비표 | 현행과 개정안을 나란히 |
| 개정문 검증 | **일치**면 개정문을 현행에 적용한 결과가 수정안과 같습니다 |
| 조문 점검 · 심의 사전검토 | 오류 · 주의 · 표기 제안 |
| 인용 영향 | 고친 조를 인용하는 조(기관 주소에서는 다른 내규·별표까지) |
| 문서 내려받기 링크 | 한글(hwpx) · Word(docx) 문서 세트. 링크를 열 때 만들어 내려받습니다 |

검증이 **불일치**이거나 점검 오류가 나오면 AI가 그대로 알려 줍니다. 그대로 쓰지 말고 고쳐 달라고 다시 요청하세요.

## 🛡️ 쓸 때 알아 둘 점

| | |
|---|---|
| **보낸 내용** | 대화와 도구 결과는 쓰는 AI 도우미 회사로 갑니다. 이 서버는 받은 원문·결과를 저장하지 않습니다. 공개 전 개정안은 기관 보안지침에 맞는 도우미에서 쓰세요 |
| **입력 길이** | 붙여 넣는 현행 원문 20만 자, 새 규정안 3만 자까지. 아주 긴 원문은 문서 링크를 만들지 못할 수 있습니다 |
| **원문으로 받은 규정** | 조문만 개정합니다. 별표·서식 개정은 기관 전용 주소에서 됩니다 |
| **많이 부르면** | 짧은 시간에 너무 많이 부르면 잠시 쉬라는 답이 옵니다. 조금 뒤 다시 요청하세요 |

## 🧰 잘 안 될 때

| 증상 | 해결 |
|---|---|
| 대화에서 도구를 쓰지 않음 | 도구 메뉴(ChatGPT는 개발자 모드)에서 커넥터가 켜져 있는지 보고, 새 대화에서 다시 요청 |
| 커넥터 추가할 때 연결 실패 | 주소 끝이 `/mcp`인지, 인증을 비워 뒀는지 확인 |
| 사용자 지정 커넥터 메뉴가 없음 | 팀·기업 요금제면 조직 관리자에게 추가 요청 |
| 알리오 검색이 비어 있음 | 규정명·기관명을 정확히 적어 다시 요청 |
